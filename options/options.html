ABOUT HINGLIFY

Translation, made simple

Hinglify is permanently connected to the public Englishtohinglish API. No API key is required. Text from pages you convert is sent to englishtohinglish.com for translation.

API endpoint: https://englishtohinglish.com/api/v1/translate · Limit: 2,000 characters/request and 30 requests/minute.
